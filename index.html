About

Five years of shipping .NET systems that stay up

I design and build scalable applications with .NET Core, Angular, and SQL Server, and I own them through deployment on Azure — App Service, Functions, Static Web Apps, and Service Bus. Along the way that's meant writing Windows Services, migrating Xamarin.Forms apps to .NET MAUI, standing up CI/CD pipelines in Azure DevOps and Jenkins, and troubleshooting the kind of routing bugs that only show up in production.

More recently I've been folding AI into that workflow: GitHub Copilot for day-to-day development, and Retrieval-Augmented Generation and agentic patterns for the LMS platform I'm building now. I care about clean architecture — repository and factory patterns, testable APIs, and services that are easy for the next engineer to pick up.
